02

What the model was trained on

three-way temporal split

An earlier version had only train/test and tuned the blend weights on the test set — hyperparameter leakage. Validation now exists: weights and model choice are selected on it, and the test window is read once. Features come from train, labels from validation, and the test window is never seen during training.
